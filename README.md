# 📝 Blog App

A full-stack blog application built with a modern frontend and backend architecture. Users can create, manage, and view blog posts through a responsive web interface.

## 🚀 Features

* ✍️ Create and publish blog posts
* 📖 View blog posts
* 📝 Edit and manage posts
* 🗑️ Delete posts
* 🔐 Backend API integration
* 📱 Responsive user interface
* ⚡ Fast and modern development setup

## 🛠️ Technologies Used

### Frontend

* React
* JavaScript
* HTML
* CSS
* Vite

### Backend

* Node.js
* Express.js
* REST API

### Database

* MongoDB
